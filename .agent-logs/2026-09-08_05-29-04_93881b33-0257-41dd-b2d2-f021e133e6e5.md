## 3. Production Rendering Strategy

### Analysis of Deployment Environments:
1. **Vercel Serverless Functions**: Standard Vercel Serverless functions have execution limits (15s on Free, 60s/300s on Pro) and bundle size constraints (50MB). Running Chrome/Chromium and FFmpeg in Vercel functions is prone to timeouts, cold-start delays, and binary limit errors.
2. **Remotion Lambda (Recommended Cloud Production Engine)**:
   - Deploy Remotion bundle directly to **AWS Lambda** using `@remotion/lambda`.
   - Renders a 7-second 1080x1920 30fps video in **2–5 seconds** by parallelizing frame rendering across multiple Lambda instances.
   - Saves final MP4 straight into S3.
   - Cost: ~$0.001 per render; completely serverless; scales automatically without timeout issues.
3. **Local Container / Railway Worker Fallback**:
   - For rapid local development or standalone container deployment, run `@remotion/renderer` inside a Docker container with Chrome and FFmpeg pre-installed.
